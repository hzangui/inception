My Inception Project

A simple Docker infrastructure project

What is Inception?

Inception is a project where we build a small web infrastructure using Docker containers.

Services

Nginx

Receives HTTPS requests from the browser.

WordPress

Runs the website and generates web pages.

MariaDB

Stores the WordPress data in a database.

Redis

Stores frequently used data in memory.

Adminer

manage databases in graphical interface.

Cadvisor

check usage of resoureces of containers.

FTP

Allows files to be transferred to the server.

How it works

Browser → Nginx → WordPress → MariaDB

Each service runs in its own Docker container and the containers communicate through a Docker network.
